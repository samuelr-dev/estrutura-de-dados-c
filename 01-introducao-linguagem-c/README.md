# 01 - Introdução à Linguagem C

Primeiros exercícios em C: declaração de variáveis, leitura e escrita de dados e cálculos com operadores aritméticos.

## Tópicos abordados

- Estrutura básica de um programa em C
- Tipos `int`, `float` e `char`
- Entrada e saída com `scanf`, `gets` e `printf`
- Operadores aritméticos e fórmulas
- Configuração de idioma com `setlocale`

## Exercícios

| Arquivo | Descrição |
|---|---|
| `ex1.c` | Média de 4 valores inteiros |
| `ex2.c` | Área de um triângulo a partir da base e da altura |
| `ex3.c` | Preço final de um produto a partir do valor e do percentual de desconto |
| `ex4.c` | Valor de x = 2ab + 3ac - 4bc a partir de a, b e c |
| `ex5.c` | Troca do valor de duas variáveis |
| `ex6.c` | Área e perímetro de um quadrado |
| `ex7.c` | Média de duas notas, exibida junto com o nome do aluno |

## Como executar

```bash
gcc ex1.c -o ex1
./ex1
```

No Windows, use `.\ex1.exe`. Nos demais exercícios, troque o nome do arquivo.
