# 03 - Laço de Repetição `for`

Exercícios sobre repetição com contador usando o laço `for`.

## Tópicos abordados

- Estrutura do laço `for`
- Acumuladores, contadores e incrementos personalizados
- Busca do maior e do menor valor
- Leitura de texto com `fgets`

## Exercícios

| Arquivo | Descrição |
|---|---|
| `ex1.c` | Escrita de uma mensagem lida do teclado 10 vezes |
| `ex2.c` | Soma, média, menor e maior de 10 números |
| `ex3.c` | Números pares entre 0 e 100 |
| `ex4.c` | Múltiplos de 3 entre 0 e 500 |

## Como executar

```bash
gcc ex1.c -o ex1
./ex1
```

No Windows, use `.\ex1.exe`. Nos demais exercícios, troque o nome do arquivo.
