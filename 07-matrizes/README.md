# 07 - Matrizes

Exercícios sobre matrizes (vetores bidimensionais) e percurso com laços aninhados.

## Tópicos abordados

- Declaração e leitura de matrizes
- Laços `for` aninhados
- Diagonal principal
- Operações sobre todos os elementos
- Formatação da saída em colunas

## Exercícios

| Arquivo | Descrição |
|---|---|
| `ex1.c` | Matriz 4x3 de números reais e o maior valor lido |
| `ex2.c` | Matriz quadrada de ordem 5 e soma da diagonal principal |
| `ex3.c` | Matriz 5x6 multiplicada por 4 e exibição do resultado |

## Como executar

```bash
gcc ex1.c -o ex1
./ex1
```

No Windows, use `.\ex1.exe`. Os três exercícios usam `system("pause")` e `system("cls")`, recursos disponíveis apenas no Windows.
