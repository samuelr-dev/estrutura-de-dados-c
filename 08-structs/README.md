# 08 - Structs

Exercício sobre estruturas heterogêneas de dados com `struct`.

## Tópicos abordados

- Declaração de `struct`
- Vetor de `struct` com dados de alunos
- Comparação de strings com `strcmp`

## Exercícios

| Arquivo | Descrição |
|---|---|
| `ex1.c` | Leitura de nome, RA, cidade e média de 3 alunos, exibindo os nomes dos que moram em Marília e o RA dos que têm a maior média |

## Como executar

```bash
gcc ex1.c -o ex1
./ex1
```

No Windows, use `.\ex1.exe`.
