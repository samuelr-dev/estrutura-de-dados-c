# 09 - Vetores de Structs

Exercícios que combinam vetores e `struct` para armazenar e processar conjuntos de registros.

## Tópicos abordados

- `typedef` com `struct`
- Vetores de `struct`
- Busca do maior e do menor valor em registros
- Cadastro com condição de parada e limite de posições

## Exercícios

| Arquivo | Descrição |
|---|---|
| `ex1.c` | Leitura de nome, RA e média de 10 alunos, exibindo o nome dos que têm a maior média e o RA dos que têm a menor |
| `ex2.c` | Agenda telefônica de até 100 contatos (nome, endereço, telefone e e-mail), com cadastro até o usuário encerrar e listagem final |

## Como executar

```bash
gcc ex1.c -o ex1
./ex1
```

No Windows, use `.\ex1.exe`. Nos demais exercícios, troque o nome do arquivo.
