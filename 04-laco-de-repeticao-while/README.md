# 04 - Laço de Repetição `while`

Exercícios sobre repetição com condição de parada testada antes de cada iteração.

## Tópicos abordados

- Estrutura do laço `while`
- Controle do laço por contador e por limite informado pelo usuário
- Somatórios
- Funções da biblioteca `math.h`

## Exercícios

| Arquivo | Descrição |
|---|---|
| `ex1.c` | Leitura de N caracteres, com N informado pelo usuário |
| `ex2.c` | Perímetro de um polígono a partir do número de lados e do valor de cada lado |
| `ex3.c` | Somatório de 3a² + a - 2 para a de 1 a 7 |
| `ex4.c` | Soma dos números inteiros entre 0 e 100 |

## Como executar

```bash
gcc ex1.c -o ex1
./ex1
```

No Windows, use `.\ex1.exe`. O `ex1.c` usa `conio.h`, disponível apenas no Windows.
