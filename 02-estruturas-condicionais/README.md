# 02 - Estruturas Condicionais

Exercícios sobre tomada de decisão com `if`, `else if` e `else`.

## Tópicos abordados

- Operadores relacionais e lógicos
- Estruturas `if`, `else if` e `else`
- Tratamento de divisão por zero
- Classificação por faixas de valores

## Exercícios

| Arquivo | Descrição |
|---|---|
| `ex1.c` | Maior, menor, soma e média de 5 números |
| `ex2.c` | Divisão de dois valores, com tratamento de divisão por zero |
| `ex3.c` | Verificação de número inteiro par ou ímpar |
| `ex4.c` | Situação do aluno (aprovado, exame ou reprovado) a partir de duas notas, com a nota necessária no exame |
| `ex5.c` | Alíquota de Imposto de Renda por faixa, a partir do salário mensal |

## Como executar

```bash
gcc ex1.c -o ex1
./ex1
```

No Windows, use `.\ex1.exe`. Nos demais exercícios, troque o nome do arquivo.
